## LoadCellHandle

A userdata object representing a **load cell handle**.

**Operations:**

| Operation   | Description |
| ----------- | ----------- |
| `LoadCellHandle` == `LoadCellHandle` | Checks if two instances of `LoadCellHandle` refer to the same `LoadCellHandle`. |

## Functions

```lua
loadCellHandle:release()
```
`Server-Only`  

[Missing Information]
