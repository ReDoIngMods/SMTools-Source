### Introduction

This website hosts documentation for custom/unofficial modding APIs for Scrap Mechanic, as provided by various mods.  
**Do note that the focus here is mainly on DLL mods providing custom Lua and/or C/C++ modding APIs.  
Lua-based ones (e.g. a workshop mod inserting things into the `sm` table) are *not* the main focus of this website.**

:::info note
This site is WIP (Work In Progress).
:::
